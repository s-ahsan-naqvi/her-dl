ARCHITECTURE

  • 🔷
    Stem: 2× Conv2D(32) with BN + ReLU6
  • 📦
    Stages 1-4: Depthwise Separable Blocks (64→512 filters) inspired by MobileNet (Howard et al. 2017)
  • 🌐
    GAP: Global Average Pooling replaces Flatten
  • 🔗
    Head: Dense(256) → Dropout(0.5) → Dense(128) → Softmax(7)
  • ⚖️
    Training: Adam · Label Smoothing (0.1) · Class Weighting for Disgust imbalance
